三層備援搜尋機制
🧠 核心理念：當 session_search 搜尋不到時，使用 MemPalace 語意搜尋
MemPalace 是拉斐爾建立的長期記憶系統，採用房間/抽屜/翅膀結構儲存語意知識。三層搜尋確保持記憶召回零遺漏。

三層詳解
P1
Phase 1 — session_search（本地對話記錄）
先用內建工具搜尋本地對話記錄，FTS5 向量搜尋，速度快、成本低
觸發條件：分數 >= 0.3 → 直接使用結果
快速
P2
Phase 2 — mempalace__mempalace_search（語意搜尋）
MemPalace MCP 工具，向量語意搜尋備援記憶系統，涵蓋領域技術棧、IF→THEN 模式、每日日記
觸發條件：Phase 1 分數 < 0.3 或結果數 = 0
備援
P3
Phase 3 — LLM Re-rank（MiniMax 語意重排序）
當 Phase 2 結果分數 < 0.4 或結果過多（> 10 條）時，使用 MiniMax LLM 對候選結果重新排序，取最高的 3-5 條
觸發條件：Phase 2 分數 < 0.4 或結果數 > 10
深度
LLM Re-rank Prompt 模板
你是記憶檢索助手。請根據以下查詢和候選記憶，評估每條記憶的相關性並重新排序。 原始查詢：{query} 候選記憶： {index}. [{source}] 相似度={score} {text_preview} 請以 JSON 格式輸出： {{"ranked": [{{"index": N, "reason": "為什麼相關", "new_score": 0-1}}]}} 只輸出 JSON，不要其他文字。
